🔄 GitOps Merge-to-Deploy Workflow

  1. Developer merges approved Pull Request into main.
  2. GitHub Actions triggers ci-cd-on-merge.yml.
  3. Docker container is built and tagged with commit SHA.
  4. Image is pushed to Amazon ECR.
  5. AI DevOps Assistant updates GitOps manifest repo with new image tag.
  6. ArgoCD detects change and performs zero-downtime rolling update on AWS EKS.
  7. Assistant posts deployment confirmation comment to the PR.
